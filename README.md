# Elena Design — WordPress theme

Главная страница портфолио Елены по макету Figma:
https://www.figma.com/design/750sY2zF8rGsTArKR8BsFO/?node-id=3-64

Адаптив: мобильный фрейм `35:40` (390 px). Типографика: `25:112`, Geist 400/500/600/700 с поддержкой кириллицы. Шрифты, изображения и SVG хранятся локально. Без Elementor, ACF, Tailwind, jQuery и этапа сборки.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP**.
2. WordPress → **Внешний вид → Темы → Добавить тему → Загрузить тему**. Загрузите ZIP и активируйте **Elena Design**. Либо поместите папку репозитория в `wp-content/themes/elena-design`.
3. `front-page.php` автоматически используется для главной. Если нужна статическая страница в настройках WordPress: создайте страницу «Главная», затем выберите её в **Настройки → Чтение → Статическая страница**.
4. **Внешний вид → Настроить → Елена — контакты и ссылки**: задайте рабочую почту, Telegram, LinkedIn, страницы услуг и ссылки на проекты.

PHP 7.4+, WordPress 6.4+. Никакие страницы или записи автоматически не создаются, существующие данные сайта не изменяются.

## Структура

- `front-page.php` — все секции главной; тексты и списки проектов, услуг, этапов и FAQ.
- `header.php`, `footer.php` — общая оболочка и подвал.
- `functions.php` — поддержка возможностей WordPress, подключение CSS/JS, настройки ссылок.
- `assets/css/main.css` — дизайн-токены, сетки, состояния и адаптивные стили.
- `assets/js/main.js` — мобильное меню, FAQ, просмотр макетов в диалоге.
- `assets/images/` — исходные изображения и SVG из Figma. `about.png` — экспорт именно декоративного блока `3:153`: его исходный image transform в Figma имеет отрицательные размеры, поэтому экспорт сохраняет точный вид кадрирования.
- `assets/fonts/` — локальные Geist и лицензия SIL OFL.
- `index.php` — базовое отображение остальных страниц и записей; `404.php` — страница ошибки.

## Поведение ссылок

- Кнопки обсуждения проекта открывают почтовое приложение; по умолчанию используется email администратора WordPress. Обязательно замените его на почту Елены перед запуском.
- Для Telegram и LinkedIn макет содержит только названия. До заполнения настроек это обычные подписи; после заполнения — ссылки.
- Проекты без отдельного URL открывают исходное изображение в диалоге. После указания ссылки карточка ведёт на страницу кейса.
- Услуги без отдельного URL открывают письмо с названием услуги в теме. После указания ссылки карточка ведёт на страницу услуги.
- «Все проекты» по умолчанию прокручивает к сетке, «Больше обо мне» — к процессу работы.
- Ссылка «Блог» появляется после заполнения её URL.
- Меню ведёт к секциям главной. FAQ работает и без JavaScript; JS оставляет открытым один вопрос. Закрытые ответы, отсутствующие в макете, дополнены нейтральным текстом — его можно изменить в массиве `$faq`.

## Соответствие макету

Сохранены подписи и изображения именно из предоставленного файла, даже где названия проектов не совпадают с содержимым скриншотов. В блоке «Обо мне» оставлена декоративная картинка, как в Figma; портрет не придуман.

Десктопный макет содержит несколько элементов, выходящих за пределы контейнера. В теме сетка помещается в ширину экрана без горизонтального скролла. Между 390 и 1440 px применяются плавные размеры контейнеров и промежуточная планшетная сетка.

Результаты проверки и ограничения описаны в `QA.md`.
